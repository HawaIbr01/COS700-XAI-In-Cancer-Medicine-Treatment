\label{sub:method_sam}
The second stage of the experimental framework introduces a targeted regularisation 
intervention by retraining the DeepCCDS model using the Sharpness-Aware Minimisation 
(SAM) optimiser. This intervention aims to collapse the generalisation gap observed 
between training and validation data performance profiles while smoothing the 
underlying parameter error landscape.

\subsubsection{Intervention Objective}
\label{ssub:method_sam_objective}
To maintain strict experimental control, the choice of parameter optimiser represents 
the sole structural distinction between the Stage 1 baseline and the Stage 2 intervention 
configurations. Both training processes enforce identical network parameter architectures, 
Z-score normalisation properties, fixed data splits, and downstream search settings. 
Consequently, this isolated architectural substitution establishes an exact empirical 
boundary to isolate the causal influence of loss landscape geometry across three primary 
dependent metric dimensions: the magnitude of the generalisation gap, the visual 
smoothness of the loss manifold, and the multi-criteria outranking scores ($\phi$) of 
the symbolic rules extracted by the evolutionary pipelines detailed in 
Sections \ref{sub:method_ga} and \ref{sub:method_nsga}.

\subsubsection{SAM Optimisation Mechanism}
\label{ssub:method_sam_mechanism}
The SAM optimisation protocol introduces an explicit neighbourhood-based adversarial 
perturbation stage into the traditional gradient calculation cycle \cite{Foret2021}. 
Rather than updating weights solely to minimise the immediate loss value computed at 
the active parameter coordinate ($\theta$), SAM evaluates the maximum worst-case loss 
expansion for all possible weight variations situated within a local Euclidean 
$\epsilon$-ball surrounding $\theta$. This yields an optimisation objective that 
minimises the loss at a perturbed parameter point defined by $\theta + \epsilon$. 
\\
By explicitly penalising regions characterised by high local curvature on the objective 
surface, SAM avoids sharp coordinate transitions and guides the parameter updates toward 
spatially stable, flatter loss landscape minima \cite{Foret2021, Li2018}.

\subsubsection{Expected Effect on Generalisation}
\label{ssub:method_sam_generalisation}
The unregularised baseline network characteristically produces exceptional training 
accuracy alongside a high validation error rate. This broad discrepancy demonstrates 
that the black box has memorised transient technical noise and dataset-specific batch 
effects instead of capturing stable biological signals. By driving parameter convergence 
toward flatter loss landscape basins, SAM regularisation is expected to reduce this 
training-validation divergence to balance performance across both data partitions. 
\\
As established by Springer et al. \cite{Springer2024}, flattening the parameter space 
enforces balanced weight distributions across active feature representations. For downstream 
rule extraction, this regularised weight profile is expected to discourage the metaheuristics from selecting 
spurious shortcuts, and to produce shorter rule strings that possess high global fidelity 
and direct alignment with authentic oncogenic pathways.
