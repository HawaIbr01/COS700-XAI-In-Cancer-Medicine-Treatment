\subsubsection{ANN: Baseline Training and Overfitting Diagnosis}
\label{ssub:method_ann}
Stage 1 begins with training the baseline deep neural network on the preprocessed 
Genomics of Drug Sensitivity in Cancer (GDSC) dataset to establish the unregularised 
overfitting baseline. This baseline serves as the quantitative starting point for the 
Red Explainable Artificial Intelligence (XAI) diagnostic pipeline. This section 
details the configuration parameters, the model selection rationale, and the specific 
geometric criteria used to confirm that the baseline model exhibits a wide generalisation 
gap prior to rule extraction.

\subsubsection{Model Selection: DeepCCDS as the Shared Platform}
\label{ssub:method_deepccds}
The DeepCCDS architecture \cite{Wu2025} is adopted as the shared deep learning platform 
for all experimental stages. Critically for the experimental control, this 
domain-specific architecture is held completely constant while being subjected to two 
distinct optimisation regimes: standard Adam without regularisation to establish the 
Stage 1 baseline, and Sharpness-Aware Minimisation (SAM) to establish the Stage 2 
intervention. This controlled substitution isolates the effect of loss landscape 
geometry on downstream explanation quality. 
\\
The primary contribution of this research is not the development of a novel neural 
network architecture from scratch, but rather the creation of the diagnostic framework 
surrounding it, consisting of the evolutionary rule extraction pipelines, the geometric 
regularisation intervention, and the multi-criteria evaluation infrastructure. Stage 1 
establishes this controlled baseline and ensures that an identical model checkpoint 
is shared across all subsequent rule extraction phases.

\subsubsection{Dataset and Preprocessing Interface}
\label{ssub:method_dataset}
The primary training data is provided by the GDSC dataset, preprocessed following the 
open-source pipeline established by Alipour \cite{Alipour2024}. The initial data 
integration steps involve merging three distinct GDSC sub-datasets comprising cell line 
genomic features, drug chemical descriptors, and screening drug response measurements. 
Following the removal of duplicate records, handling of missing feature entries, and 
one-hot encoding of categorical features, a structured tabular dataset is produced. Each 
row represents a unique cell line--drug combination characterised by high-dimensional 
gene expression features and a continuous drug sensitivity target quantified via the 
natural logarithm of the half-maximal inhibitory concentration ($\text{LN } IC_{50}$). 
\\
Prior to model training, additional preprocessing operations are applied to maintain 
strict compatibility with the DeepCCDS engine and the downstream symbolic rule extraction 
pipeline. The continuous gene expression variables are Z-score normalised across all 
samples, ensuring that individual gene expression values are expressed relative to the 
population mean and standard deviation. For the downstream symbolic rule extraction 
stage, these continuous inputs are discretised into biological categories: High 
Expression ($Z > 1$), Low Expression ($Z < -1$), and Intermediate Expression 
($-1 \le Z \le 1$). The dataset is partitioned into a fixed 80\% training, 10\% 
validation, and 10\% testing split prior to any model optimization. This split 
functions as a locked interface specification across the entire pipeline, ensuring 
that all rule-quality metrics are computed on identical, uncorrupted held-out data 
throughout the study.

\subsubsection{Stage 1: Training the Overfitting Baseline}
\label{ssub:method_training}
The baseline model is optimised using the Adam optimiser with a fixed learning rate 
of 0.001, operating with no explicit regularisation penalties such as weight decay 
or dropout mechanisms. To ensure that clear overfitting and explanation fragility 
emerge, training is driven past the point of optimal generalisation. This is 
achieved by applying an early stopping criterion in reverse: training continues with 
a strict patience parameter of 30 epochs, used not to halt training prematurely, but 
to confirm that the generalisation gap has completely stabilised \cite{Goodfellow2016}. 
The stopping point is defined as the epoch at which the training loss decreases 
continuously while the validation loss has plateaued or increased for at least 10 
consecutive epochs. The generalisation gap is formally calculated as:
\begin{equation}
    \text{Generalisation Gap} = \text{Validation Loss} - \text{Training Loss}
\end{equation}
The magnitude of this resulting gap is recorded using the coefficient of determination 
($R^2$) and the Root Mean Squared Error ($\text{RMSE}$) on the continuous 
$\text{LN } IC_{50}$ regression target to define the confirmed Fragility Baseline. 

\noindent
Because a standardised generalisation-gap threshold is absent in the pharmacogenomic 
deep learning literature, the baseline gap is evaluated relative to the regularised performance 
benchmarks published for DeepCCDS \cite{Wu2025}. Overfitting is confirmed when the 
unregularised baseline yields exceptionally high training accuracy alongside a severe 
performance degradation on the test set relative to the published reference. The trained 
baseline weights are then saved as a static checkpoint, ensuring that the downstream 
evolutionary rule extraction algorithms operate on an identical model state.

\subsubsection{Confirming the Clever Hans Baseline}
\label{ssub:method_cleverhans}
A qualitative sanity check audits the baseline model for Clever Hans behaviour, 
following the framework outlined by Pahde et al. \cite{Pahde2023}. This check 
generates local feature-attribution maps for a representative sample of training and 
validation predictions. These maps are built using a lightweight Layer-wise Relevance 
Propagation (LRP) implementation alongside vanilla input gradients—a technique that 
uses backpropagation to calculate the partial derivatives of the model's output with 
respect to the input features, measuring how sensitive a prediction is to small changes 
in each gene's expression.
\\
When the unregularised baseline model exploits non-biological statistical noise, the 
resulting training attribution maps display diffuse, scattered, or biologically 
incoherent relevance signatures. Specifically, the model assigns high marginal 
importance to housekeeping genes or technical artefacts that possess no documented 
functional roles in established oncogenic pathways. Concurrently, validation 
attribution patterns exhibit high sample-to-sample inconsistency. This qualitative 
assessment exposes the explicit structural fragility of the unregularised model's 
internal logic, providing the scorecards that establish the Fragility Baseline.
